# SmartXm Remote Server

A minimal PHP website with user authentication, profile viewing, and profile editing. Users have a name, email, password, student ID, and role (Teacher or Student).


## Features

- Login page
- Profile page (view user info)
- Profile edit page (edit name, email, password, student ID, role)
- MySQL database backend
- Secure password hashing
- Session-based authentication

## Requirements

- PHP 7.2+
- MySQL/MariaDB
- Web server (e.g., Apache, Nginx)

## Setup Instructions

### 1. Database Setup

1. Create the database and user table using the following SQL:

```sql
CREATE DATABASE IF NOT EXISTS simple_php_site CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE simple_php_site;

CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    student_id VARCHAR(50) NOT NULL UNIQUE,
    role ENUM('Teacher', 'Student') NOT NULL DEFAULT 'Student',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

> **Tip:** Generate a password hash in PHP with:
> `<?php echo password_hash('password123', PASSWORD_DEFAULT); ?>`

### 2. Configure Database Connection

Edit `includes/db.php` if your MySQL credentials differ from the defaults:

```php
$host = 'localhost';
$db   = 'simple_php_site';
$user = 'root';
$pass = '';
```

### 3. Deploy the Site

- Place the `simple-php-site` directory in your web server's root.
- Ensure the web server user has permission to read/write the directory.
- Access the site via `http://localhost/simple-php-site/` (or your server's URL).

### 4. Usage

- Visit `/pages/login.php` to log in.
- After login, you'll be redirected to your profile.
- Edit your profile via `/pages/edit_profile.php`.
- Log out via `/pages/logout.php`.

## Security Notes

- Passwords are hashed using PHP's `password_hash`.
- Sessions are used for authentication.
- Always use HTTPS in production.
- Change default database credentials before deploying.
